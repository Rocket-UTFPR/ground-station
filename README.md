## Como configurar o mapa
Faça o download do mapa e extraia o arquivo .map para o diretório maps.
- Exemplo: ```maps/Brasil-Coast-South_oam.osm.map```.

Sugestão de sites para baixar o mapa:
- https://extract.bbbike.org/
- https://www.openandromaps.org/en/downloads/south-and-middle-america
